# Scripts associated with the manuscript "Spatial and temporal variation of pollen signature of grapevine and associated Mediterranean vegetation inferred by deep learning". Ecological Informatics (under review).

This repository contains the Python and R scripts used in the study: "Spatial and temporal variation of pollen signature of grapevine and associated Mediterranean vegetation inferred by deep learning". Ecological Informatics (under review).

The scripts were used to :
* 1_classification : Train and evaluate the classification models; and 
* 2_application : Generate prediction on images from the pollen monitoring study and study spatial and temporal variation in pollen assemblages.


## Repository organization :


The scripts are numbered and should be run in numerical order, as later scripts depend on the outputs generated by previous ones.

Scripts beginning with "get_" or "table_" generate intermediate ".csv" files that are subsequently used to produce other tables or to produce figures.


## Associated data

The first section (1_classification) relies on the image dataset POLLEN54M, and associated files available in the ZENODO repository 10.5281/zenodo.22011920 : including the classification dataset POLLEN54M and associated files (model trained weights, prediction vectors, etc.).

The second section (2_application) relies on the image dataset POLLENmonit-PSL, and associated files available in the ZENODO repository 10.5281/zenodo.22142820 : including the pollen rain monitoring image dataset POLLENmonit-PSL and associated files (prediction vectors, pollen count tables, etc.).

## Details for each file in the `1_classification` section

The files in this section correspond to the preparation, training, evaluation, and analysis of the pollen image classification dataset.

### (a) Dataset preparation

* **`01_fig2_classification_dataset.ipynb`**

  Generates the bar plot showing the number of reference images (from the pollen collection) and environmental images (from pollen traps) included in each class of the classification dataset.

* **`02_augmentations_debris_cover.ipynb`**

  Generates an augmented version of the classification dataset containing the same images as the original dataset, with synthetic debris added to the images. This augmentation was designed to mimic debris frequently observed in environmental pollen-trap samples while retaining sufficient visibility of the pollen grains for accurate identification.

* **`03_padding.ipynb`**

  Adds black-pixel padding to each image to obtain a standardized square format while preserving the original aspect ratio and the relative size of the pollen grain. A separate dataset containing the processed images is generated.

* **`04_split_df_10folds.ipynb`**

  Splits the dataset into 10 subsets of approximately equal size. These subsets are used to define the training, validation, and test sets for the 10-fold cross-validation procedure.

### (b) Model training and evaluation

* **`05_train.py`**

  Trains the ResNet152 classification models using 10-fold cross-validation.

* **`06_plot_history.ipynb`**

  Generates the learning curves showing training and validation loss and accuracy for each cross-validation fold.

* **`07_get_F1_weights.ipynb`**

  Generates a table containing the F1-scores obtained for each model and each of the 18 target pollen taxa. These F1-scores are subsequently used to calculate the model weights for the fractional prediction approach.

* **`08_table_performance_metrics.ipynb`**

  Generates the performance metrics tables and values for the 18 target pollen taxa using the fractional prediction approach and considering environmental images only.

* **`09_fig2_confusion_matrix_env_frac.ipynb`**

  Generates the confusion matrix figures for the 18 target pollen taxa using the fractional prediction approach and considering environmental images only.

* **`10_tableA1_54cl_Top1.ipynb`**

  Generates the performance metrics tables and values for all 54 classes using the top-1 prediction approach, in which the class with the highest predicted score is assigned as the predicted class (presented in Appendix in the associated publication).

* **`11_figureApp_A4A5_confusion_matrix_54cl_top1.ipynb`**

  Generates the confusion matrices for all 54 classes using the top-1 prediction approach, in which the class with the highest predicted score is assigned as the predicted class (presented in Appendix in the associated publication).


## Details for each file in the `2_application` section

The files in this section apply the trained classification models to the pollen-trap images and generate the pollen counts, percentages, fluxes, and statistical analyses presented in the manuscript.


### (a) Model predictions and pollen counts

* **`01_model_predictions.py`**

  Generates predictions for new pollen images using all 10 models obtained through cross-validation. This script was used to generate predictions for all **281,518 images** from the pollen-rain monitoring study analyzed in the associated manuscript (and available in the associated Zenodo repository).

* **`02_combine_predictions.ipynb`**

  Combines the predictions generated by the 10 cross-validated models for each image using the weighted fractional prediction workflow described in the manuscript. This produces a single prediction vector containing 18 scores for each image, corresponding to the 18 target pollen classes.

* **`03_table_pollen_counts_perc.ipynb`**

  Generates tables of automated pollen counts for each pollen taxon and each slide, aggregates the counts for each pollen trap, and calculates pollen counts and percentages for each trap.

* **`04_table_pollen_fluxes.ipynb`**

  Generates tables of pollen fluxes for each pollen trap and pollen taxon.

* **`05_table_perc_AC.ipynb`**

  Generates the percentage tables used for the correspondence analyses, including pollen percentages by site and year, as well as pollen assemblages aggregated by site across years.

### (b) Figures

All tables required to generate the figures can be reproduced using the scripts presented here. For convenience, the tables generated immediately prior to figure production are also provided in the repository.

* **`Fig3_flux_grapevine.ipynb`**

  Generates the figures showing grapevine pollen fluxes for each pollen trap.

* **`Fig4_assemblages_percentages.ipynb`**

  Generates the figures showing pollen percentages for each pollen trap, across sites and over the full study period.

* **`Fig5_assemblages_fluxes.ipynb`**

  Generates the figures showing pollen fluxes for each pollen trap.

* **`Fig4-6_correspondence_analysis.ipynb`**

  Generates the correspondence analysis figures based on pollen assemblages, including analyses by pollen trap (site and year) and analyses of pollen assemblages across years within each site.
